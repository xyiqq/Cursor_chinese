# Cursor 更新后重建中文快捷方式并加强自愈

## 目标

Cursor 更新到 3.20.10 后桌面「Cursor中文」再次消失，汉化也被冲掉；立即恢复，并减少以后再丢快捷方式的概率。

## 做了什么

1. 执行 `--an-zhuang`：重新注入汉化、重建 VBS、重建桌面快捷方式
2. 自愈时若桌面快捷方式缺失，会自动补回
3. 额外在「开始菜单」放一份「Cursor中文」备份

## 改了哪些文件

- `CursorHanHua_GongJu.py`
- 本机生成：桌面/开始菜单 `Cursor中文.lnk`、`QiDong_Cursor_ZhongWen.vbs`

## 怎么验证

1. 桌面与开始菜单都能看到「Cursor中文」
2. 完全退出后用该快捷方式启动，界面为中文

## 风险/未完成

- Cursor 官方更新仍会冲掉注入；必须用「Cursor中文」启动才会自动修
- 若用户从不运行本工具/快捷方式，桌面图标仍可能被手动删除且不会自己回来
