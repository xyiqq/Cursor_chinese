# 减轻最新版 Cursor 闪屏

## 目标

Cursor 3.24.x 出现客户端闪屏时，区分官方 GPU/主题问题与本工具用量条周期性重建 DOM。

## 做了什么

优化汉化脚本用量刷新：

- 用量数值未变化时不再 `replaceChild` 重建用量条
- 页面轮询改为 60 秒，且仅读 `usage_live.json`；无文件时才回退官网请求
- 避免无意义的周期性 DOM 刷新导致聊天区闪一下

## 改了哪些文件

- `CursorHanHua_GongJu.py`

## 怎么验证

1. `python CursorHanHua_GongJu.py` 后完全退出并用「Cursor中文」启动
2. 静置观察：不应再出现约每 20 秒规律性闪一下
3. 若仍整窗持续闪：按下方官方规避尝试

## 风险/未完成 / 官方规避

若仍闪（尤其 Agent 面板整窗闪），多为 Cursor 官方问题，可依次试：

1. 设置 → Appearance：不要用「Cursor Dark High Contrast」，改用 Cursor Dark / Cursor Light
2. `Ctrl+Shift+P` → Preferences: Configure Runtime Arguments，加入 `"disable-hardware-acceleration": true` 后完全重启
3. Windows 显示缩放从 150% 试降到 125%
4. 临时验证：`python CursorHanHua_GongJu.py --huifu` 恢复英文，若闪屏消失再重新 `--an-zhuang`，可确认是否与汉化有关
