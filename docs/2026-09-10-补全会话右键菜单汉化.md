# 补全会话右键菜单汉化

## 目标

把会话列表右键菜单中仍显示英文的条目译成中文。

## 做了什么

在 `FanYi_CiDian` 中新增会话右键菜单映射：

| 英文 | 中文 |
|------|------|
| Pin / Unpin | 固定 / 取消固定 |
| Rename | 重命名 |
| Edit Icon | 编辑图标 |
| Mark as Unread / Mark as Read | 标为未读 / 标为已读 |
| Fork | 分叉 |
| Move to | 移动到 |
| Archive / Unarchive | 归档 / 取消归档 |

## 改了哪些文件

- `CursorHanHua_GongJu.py`

## 怎么验证

1. 运行 `python CursorHanHua_GongJu.py` 重新注入
2. 完全退出并用「Cursor中文」启动
3. 在会话列表右键，确认上述条目为中文

## 风险/未完成

- `Archive` / `Pin` / `Rename` 为全局精确匹配，其他场景同文案也会被译成中文
- 子菜单里若还有动态文件夹名，仅翻译「移动到」本身
